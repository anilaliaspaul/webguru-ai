# Roadmap

## v1.0.0 — Core skill

- Interactive mode selection and input collection.
- Website inventory and 12-category QA audit.
- Defect register and evidence-based reporting.
- Authorized source-code defect resolution.
- Regression testing and independent re-audit.
- Claude Code and Codex packaging.

## Future improvements

- Optional Playwright starter test suite templates.
- Standardized machine-readable QA report export.
- Reusable defect-tracker import/export formats.
- CI pipeline examples for pre-merge and pre-release quality gates.
- Optional website-type profiles for e-commerce, SaaS, nonprofit, and corporate websites.

Future capabilities must remain optional and must not imply tool access the host does not provide.
